## Module Summary

This module applies core network security concepts to detecting discovery, data exfiltration and man-in-the-middle activity, then translates packet and log observations into IDS alerts and Snort rule analysis.

---

## Skills Covered

- Firewall, VPN, IDS, DNS and flow monitoring
- Network discovery and scan detection
- Data exfiltration and DNS anomaly investigation
- ARP poisoning and man-in-the-middle indicators
- IDS alert validation and false-positive analysis
- Snort rule interpretation and practical command-line usage
