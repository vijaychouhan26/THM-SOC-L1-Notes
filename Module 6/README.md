## SOC Analyst Skills Practised

- Extract meaningful indicators from logs, traffic or security artifacts.
- Preserve timestamps, context and evidence provenance.
- Separate suspicious activity from confirmed malicious activity.
- Record an actionable verdict, uncertainty and escalation recommendation.
