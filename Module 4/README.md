## Module Summary

This module connects defensive frameworks to practical SOC investigation. The rooms cover the Pyramid of Pain, Cyber Kill Chain, Unified Kill Chain, MITRE ATT&CK, and practical scenarios that apply these frameworks to detection and threat analysis.
