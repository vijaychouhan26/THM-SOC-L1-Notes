## Module Summary

The SOC relies on several connected security technologies. EDR provides deep endpoint visibility and response capabilities, while SIEM centralizes logs and correlates events across the environment. Splunk and Elastic provide practical platforms for log investigation, and SOAR adds orchestration and automation to repeatable response workflows.
