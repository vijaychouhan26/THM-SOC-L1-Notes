## Module Summary

The module begins with Windows Security, Sysmon and PowerShell evidence, then applies those sources to common attacker behavior. The investigation model is timeline-based: identify the access session, follow related processes and files, pivot into network activity, and verify any persistence or impact.

---

## Skills Covered

- Reading and filtering Windows EVTX logs
- Interpreting authentication and account-management events
- Building process trees with Security and Sysmon telemetry
- Correlating Logon ID, Process ID, file, registry, DNS and network evidence
- Detecting RDP, phishing and removable-media initial access
- Investigating discovery, collection and tool transfer
- Identifying C2 and common Windows persistence mechanisms
- Separating suspicious behavior from confirmed malicious impact
