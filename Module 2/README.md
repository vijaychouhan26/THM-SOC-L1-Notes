## Module Summary

A SOC analyst needs more than technical knowledge. Effective operations depend on a repeatable triage process, accurate reporting, useful context from workbooks and lookups, measurable performance, and clear escalation and communication.

This module builds those operational skills before moving into the core technical SOC solutions covered in Module 3.

---

## Skills Covered

- Alert classification and triage
- IOC extraction and verification
- Five Ws incident reporting
- Escalation to L2
- SOC workbooks and asset lookups
- Network and identity context
- MTTD, MTTA, MTTR and FPR
- SLA awareness
- Phishing identification and analysis
